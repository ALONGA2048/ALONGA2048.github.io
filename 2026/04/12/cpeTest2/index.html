# uva. 10079 Pizza Cutting

題目:

你pizza都是如何切的呢? 每次切pizza的時候幾刀能將一個pizza切成幾份呢?
這個題目要你想看看每次切pizza的刀數能達成的最大塊數
Input
The input file will contain a single integer N (0 ≤ N ≤ 210000000) in each line representing the number
of straight line cuts one makes through the pizza. A negative number terminates the input.
Output
Output the maximum number of pizza pieces the given number of cuts c

Sample Input
5
10
-100
Sample Output
16
56

解題思路:

  • 這種數學計算題目通常是要找一定的規律寫成程式碼,因此先模擬列舉出來
  • 掌握他的規律 如這題最後會發現其初始為f(n+1) = f(n) +n 能用遞迴解 或寫成速解公式f(n) = (n*n+n+2)//2 (級數和公式)
  • 查看他的輸入輸出條件(EOF 輸入直到出現負數代表結束)

import sys

for line in sys.stdin:
    a = int(line)
    if a<=0 :
        break
    else :
        print((a*a+a+2)//2)

# uva. 11321 Sort! Sort!! And Sort!!!

    需要寫一個程式來進行數字的排序
    而排序的規則按照
    1. 餘數最大的排前面
    2. 餘數相同 則原數字奇比偶數前 
    3. 同奇數 升序
    4. 同偶數 降序
    5. 按照C語言的餘數標準(負數的餘數為負數)

解題思路:

  • 用一個cmp_to_key(類似java Comparotor的概念) 自定義其排列方式並傳入
  • 記得自己寫一個C語言的求餘數函式
  • 按照其要求讀數列直到輸入0 0 則為EOF訊號

import sys
from functools import cmp_to_key

def get_mod(n, m):
    # 先都當正數 有負號處裡完再加入
    res = abs(n) % m
    return res if n >= 0 else -res

# 比較條件
def compare(a,b,m):
    mod_a = get_mod(a,m)
    mod_b = get_mod(b,m)
    # 以下為題目設定條件(return 1 是順序不動 -1 是調換順序 ) 

    # 若餘數不相等 直接以大小排序
    if mod_a!=mod_b :
        return -1 if mod_a < mod_b else 1
    

    is_a_odd = a% 2 !=0
    is_b_odd = b% 2 !=0

    # 若 一奇一偶 則奇在前
    if is_a_odd and not is_b_odd :
        return -1
    if not is_a_odd and  is_b_odd :
        return 1
    # 兩奇數 大者在前 (降序)
    if is_a_odd and is_b_odd:
        if a>b : return -1
        if a<b : return 1
    # 兩偶數 大者在後 (升序)
    if not is_a_odd  and not is_b_odd:
        if a<b : return -1
        if a>b : return 1
        
    return 0    
while True:
    line = input() 
    if  line == "0 0" :
        print(line)
        break
    else :
        print(line)
        time,mod = map(int,line.split(" "))
        
        nums = []
        for _ in range(time):
            nums.append(int(input()))
        nums.sort(key= cmp_to_key(lambda a,b : compare(a,b,mod)))
        for num in nums:
            print(num)
